# Pacifica Workshop

Custom cabinetry site for the workshop division of Atelier Pacifica.

## Preview on Vercel

1. Import this repository into Vercel: https://vercel.com/new
2. Upload the `project_images` folder (optimized versions available locally) via the GitHub web interface or git.
3. Deploy. The site is a static HTML/CSS site.

Real project photography from Bluewater and 29200 Larkspur is referenced in `project_images/`.
